# Dino Run development rules

## Scope, platform and licence

- Work only in NQUAREx/DinoPlat3d. Never modify/publish the separate live original NQUAREx/dinoplat.github.io.
- Static Three.js 0.186.1 + TypeScript + Vite application for GitHub Pages; no backend, CDN, physics/particle engine or new runtime dependency without need. npm run dev / build / preview must keep working.
- Owner approved GPL-3.0-only. Preserve LICENSE, public licence/source links and original imported VOX archives/attribution: hushenghao/dino3d commit cae7ed3da5646839e6aaa24f698b8c07cc3ffc85, ©2020 Abraham Tugalov. Never copy upstream gameplay code. Imported dinosaur/cactus VOX files are archival only, never runtime assets or model-builder inputs.
- Use local geometry/animation skills when applicable. I/O/model loading/authoring is async and parallel where useful. Fixed-step simulation, gesture state and RAF rendering remain synchronous: no promises/microtasks in hot loops.

## Art direction

- Saturated child-friendly cartoon low-poly 3D with pixel UI. Sky #73d8ff, ink #24374d, lime #7be344/#43b52c, cream #fff2c3, coral #ff704c. No realistic grit, washed-out palette, PBR, postprocessing, outlines, bloom or heavy textures.
- Dinosaur now follows the owner's watch/keyring references: angular/chamfered long muzzle, upright tapered turquoise-green body/neck, large white eyes, cream belly, tiny white teeth, coral dorsal plates and tapered tail. NOT voxel cubes or a round ball character. Original editable source tools/low-poly-dinosaur.mjs; 788 triangles / 11 bones / five cached run, jump, duck, hit, death clips. Stable body collider is independent of head/tail art.
- Seven original cactus silhouettes in the general chunky Brawl Stars aesthetic, not copied assets. Broad bevels/soft authored normals, green ribs, pale areoles, enlarged cream/yellow spines and green rounded bumps, flowers and 2–8 enlarged varied low-poly stones. One indexed packed-Uint8 vertex-colour mesh per variant, no separate per-spine/stone scene objects, textures or materials. Detailed counts 750/774/468/930/886/810/936; cap950. Preserve collider envelopes and 2× registry/load scale.
- Each cactus has one offline low LOD: 192/192/48/192/168/192/192 triangles, no spines/stones/flowers. Use the SAME detailed-model normalization transform for its simplified core; never independently resize LOD bounds. Seven detailed plus seven low meshes are preloaded in game-models.glb (27 meshes / 653724 bytes total including four skinned palettes, six accessories and three pickups). No gameplay-time network/model generation.
- LOD uses pooled instanced banks, not one THREE.LOD/Object3D per cactus. Detailed within22m of player, low beyond30m, complementary opaque 4×4 screen-door dithering between. No transparent double silhouettes, allocation or abrupt swaps. Instanced detail attributes use cached live-prefix upload ranges. Both variants retain identical world transform/yaw/base.
- Pickups are original volumetric low-poly beveled gold coin, faceted cyan diamond and beveled red heart matching HUD palettes: 192/48/84 triangles. Source tools/low-poly-collectibles.mjs; build via npm run collectibles:build. Old VOX collectibles are archival only. Three cached geometries/material bank, one shared 2.4s spin/bob phase ±.1m, conservative yaw-invariant bounds and swept animated vertical overlap.
- Press Start 2P Cyrillic local WOFF2, square stepped buttons, hard pixel borders and original optimized <=32px HUD icons. Pixel filtering belongs to icons/fonts/terrain magnification, NOT the whole canvas: #game image-rendering:auto. Menus centred; running shows only full-width top HUD, bottom-left >=48px pause and bottom-right >=48px camera toggle and requested temporary 2D item notices. No hints/decorative running text.

## Movement and floating origin

- Main menu exists only on startup/Game Over. Connected square Home/Shop/Settings tabs are consecutive from top-left, without spacers or motivational copy. Pause is separate: only Resume and Settings, no Home/Shop/end-run/camera actions. Shared settings return to their originating menu. Shop has four dinosaurs and three hats/shoes per horizontal rail; every locked price has its actual currency icon. Existing prices are tripled, gold dinosaur is exactly1000diamonds. Never enable page scrolling/selection; dragging must not purchase/equip.
- Home has a larger touch-rotatable live dinosaur with equipped skin/hat/shoes. MenuPreview shares the existing renderer and cached geometry, owns one cloned rig/material and three reusable attachments, renders only on requested menu frames, no idle RAF/second WebGL context. Clear/scissor the preview without drawing the world during drag; restore viewport/scissor state. Dispose cloned skeleton/material once, not shared geometry. Boots have closed thicker soles and a visual-only .04m root lift, no collider changes.
- CosmeticInventory validates a fixed catalogue, purchases with Wallet.spend and persists owned/equipped IDs in dinorun-cosmetics-v1 localStorage. Green is always free/default; white/pink/gold palettes share the same rig/layout, no physics changes. Three hats and three shoe models are authored offline (56/96/60 and72/72/72 triangles), preloaded; one head and two shin attachments reuse cached meshes/materials and follow all clips. Swapping skins/accessories must not allocate meshes, modify collider bounds, reset wallet or trigger pickup sounds. WalletChanged persists spending separately from Pickup. Client-side storage is not secure/atomic multi-tab economy.
- Visible title is Dino Run; preserve repository URL and existing wallet/settings keys. Bottom-right camera toggle switches to first person (FOV65/near.08, eye1.45m + jump -.65m duck), same .42s smoothed heading as third person, hidden avatar/contact ellipse and skipped mixer CPU when fully inside the head. Third person keeps FOV50/near.2 and .42s delayed heading. Mode survives run resets; no renderer allocation. Position/quaternion/FOV/near blend for .65s using (1-cos(πt))/2; reversal starts from the current blend. Camera switches during play schedule bounded transition RAFs; lifecycle/background still stop RAF.
- Touch-only portrait-only, no keyboard/mouse controls, lanes, lateral bounds or road edges. Hold either screen half to TURN continuously at1.6rad/s. Release stops turning, not running; keep the new heading. Unwrapped heading can cross ±π and full rotations without snaps.
- Simulation is DOM/Three-independent and fixed120Hz. X and logical Z are independent Float64 world coordinates; Y is jump height. Forward at heading0 is +worldZ / -renderZ. Velocity = (-sin(heading), cos(heading))*speed, integrated at midpoint heading. Speed12–24m/s, never zero except explicit pause/hit stop/Game Over. distance is monotonic travelled path length, NEVER a world coordinate.
- RenderPose interpolates x,z,heading AND path distance separately. Subtract pose.x/pose.z before writing any Float32 world geometry/instances/dust; avatar remains local X/Z zero. Ground, camera, shadows and all renderers must use that same origin at million-metre/negative coordinates. Never use path distance for object/world Z transforms.
- Camera orbits behind heading with .42s exponential follow delay and unwrapped interpolation, no seam snap. Baseline height8.5/distance12/lookY1/lookZ-5/FOV50/far96, fog36–84. setPose stays relative to running direction. Preserve event-driven extension points and reduced motion.
- Damage/jump/duck use swept full X/Z slab intervals, including reverse and zero delta on either axis, plus interpolated feet/body top and pickup bob. Blocking body radius.22 and cactus X/Z half extents scaled.65; pickups retain radius.32/full extents. Keep full render/culling/generation bounds unchanged and coarse Z rejection before registry lookup. Standing1.3/duck.65m, jump velocity13.3/gravity22. Decorative parts do not enlarge collisions.
- Swipe up jumps only on ground and cancels duck; swipe down dives continuously at minimum22m/s in air, or ducks .85s on ground with .083s blend. Landing once, never teleport. No overhead obstacles until requested. Bone duck animation follows stable physics, not compressed root scale. Trim cached duck clip to.65s; run and duck legs use travelled-distance phase, never glide.
- Every damaging contact clamps the swept impact point and freezes world, animation clocks, bonuses, immunity and dust for exactly1s, including fatal hits. Only floating feedback clock and impact shake advance. Never emit footsteps on the impact tick. Fatal freeze enters dying for1.25s: frozen bone pose, root-only sideways fall/recoil/two damped bounces, world/path/speed clocks stopped, then Home. First-person fatal hits return the camera to rear view to show the fall; restore chosen mode next run. Nonfatal hits retain full2s immunity and start speed12. Manual pause preserves dying/running phase and all clocks; restart clears effects except wallet/equipment.

## Numeric generation and culling

- WorldSpawner is a deterministic symmetric 15×15 chunk ring,16m chunks, six obstacle + four separate pickup candidates: fixed2250 numeric slots. Support every heading and both signs of X/Z. No per-obstacle meshes, growing history/cache or geometry work outside view. Resident numeric guard data allows safe turns/revisits without near-camera pop-in; actual model submission is full-AABB camera culled (plus bounded shadow-caster guard). Do not equate cheap numeric candidates with rendered/spawned 3D objects.
- Continuous random coordinates, not jittered lanes/rows. Radial startup clearing28m for cacti/12m pickups and radial distance-based density keep negative coordinates valid and field deterministic through reentry/slowdown. Hard-core thinning avoids clusters. Pickup RNG/group250:10:1 plus independent90% pickup candidate gate is isolated from cactus RNG/selection and rejects candidates inside cacti.
- Keep safe continuous routes starting X0 and spaced32m with derivative<=.081 and full cactus/yaw/body/reaction padding. Route-following tests must use heading steering, not the removed lateral velocity API. Verify100 seeds ×300s at24m/s with300ms delayed pilot and all3 lives; do not mask failures with immunity/hearts.
- ObjectRegistry/definition metadata owns collider variants, kinds, weights, bonuses/healing, animation and reserved destruction metadata. Wallet/bonus/enemy/destruction contracts stay extensible; active bonuses/enemies/destruction are NOT implemented. One pickup consumed once while chunk retained. Future speed bonuses respect generation max24 budget.

## Terrain

- Authored pixel atlas remains local and unchanged:97 independent128² layers (64 base variants, shared stone,16 entries,16 exits), ~8.1MiB GPU RGBA/mips. Nearest magnification, trilinear minification, anisotropy<=2; one textureGrad albedo lookup using derivatives computed BEFORE region branches. Standard Lambert normals/fog/shadow pipeline, no overlays/PBR/displacement.
- 2.5m tile scale; seeded non-mirrored variants. Keep whole tile identity wrapped modulo65536 in shader AND CPU to avoid negative/wrapped-anchor jitter. World-anchored mesh/UVs, never scroll a stationary camera-local plane.
- Turning/backtracking requires world-fixed biomes: TerrainField has seeded500×500m regions in BOTH axes, origin offsets137.5/91.25m keep spawn away from seams. Neighbour-distinct checkerboard palettes give all16 types equal probability. Odometer milestones remain independent metadata; visible biome must never rotate/slide/change on revisits merely because distance increased.
- Every spatial boundary keeps exact authored transitions from art/terrain-transitions-attached.jpg:4×4 crops/full painted interiors; 1.25m material→stone,2.5m stone,1.25m180° rotated stone→material, rotated90° for X boundaries. Common-stone junctions hide corners. No base/stone mask replacement or N² assets. Source PNG/JPGs stay out of dist.
- TerrainSurface is one indexed224m/28×28 mesh,1568 triangles, anchored to8m cells and centred for all headings. Flat today's physics; retain height-provider hooks for future relief/decoration, do not claim uneven-ground locomotion. Flat origin rebases must NOT upload geometry/recompute normals; only changed height providers/actual relief need that work.

## Rendering, shadows and feedback

- One key DirectionalLight plus HemisphereLight,360s day, interpolated world time. Opposite-side virtual moonrise uses smooth dimmed overhead twilight handoff; all ambient/fog/light/shadow colours continuous. NO visible moon or second hidden sun/shadow pass. setTimeOfDay, setSunPosition and ?time debug controls retained.
- Shadow focus follows delayed camera direction without rotating celestial direction with the player. Preserve one256² BasicShadowMap (colour/native depth), cached8Hz/4Hz minimum quality, origin rebase and light-camera texel snapping. Map/casters refresh on reset/new chunks/manual light/context restore/large origin changes, not sun/moon label switches. Cacti cast; only ground receives, no unnecessary cactus-fragment lookups. No quality-based shadow disabling (~170m old bug). Dispose target once, never double-dispose native depth.
- Dinosaur contact ellipse:16 triangles/one draw, black alpha, interpolated jump/yaw/duck/immunity/day/night, no second capture. Dust is256 pooled opaque 8-triangle octahedra in one instanced draw,42 per step/72 on landing, .85s life with pooled lift variation. World-anchored heading-relative trails, reduced-motion suppression, no shadows. Walking bob is1.5× previous build (2.25× old original), landing impulse.0525/.2s; shake multiplier is fixed2.9 (290%); no slider or persisted shake setting. First-person effects ×1.3 and third-person effects ×.85 relative to the previous build; blend their amplitudes during camera travel. Reduced-motion suppression remains.
- Floating feedback is twelve reusable 2D DOM labels above rendered dinosaur, not sprites/meshes. +1 coin/diamond/heart, -1 heart, MAX on full-health heart; .95s expiry, pool/restart cleanup and registerable future icons. Separate feedback clock runs through hit freeze, not manual pause.
- CRITICAL Three r186 upload epoch: visibility traversal updates frameN, then shadow capture stamps N+1. Next traversal can skip fresh instance matrices. View.draw increments renderer.info.render.frame BEFORE renderer.render. Preserve until real GPU readback regressions pass; never work around stale uploads with simulation rollback, timing smoothing or new buffers. Readback is TEST-ONLY, no synchronous GL inspection in RAF.
- RenderQuality: cap DPR2/1.3M physical pixels, keep at least1 CSS pixel per pixel on ordinary phone viewports, never nearest-upscale canvas. Request lightweight native MSAA, default powerPreference (not forced low-power/discrete GPU). Stable30Hz must NOT trigger downscaling. Reduce by.1 only after sustained >40ms frame intervals and6s cooldown; recover .05 after12s healthy<35ms, quality floor.6. Hysteresis/lifecycle stops preserved; no claim this overrides OS Low Power/thermal/display caps.
- Budget after warming all variants: <=38 draws on an LOD-overlap shadow-capture frame with equipped hat/shoes (<=24 otherwise), <=30 warmed geometries /5 textures (atlas,shadow colour/depth,two bone textures). LOD costs an extra instanced bank but saves distant triangles. No hot-loop allocations; cached matrices/ranges/materials; submit only live prefixes. All GPU/model/instance/listener ownership disposes once, including context loss/HMR/asset failures.

## Touch/browser shell, storage and tests

- Pending touch must not steer on pointerdown. Vertical up/down exclusively classifies jump/dive/duck; stationary hold36ms, horizontal intent>2.7px immediately. A moving pending finger must not timeout into steering, a committed hold cannot become jump later. Crossing midpoint reverses turning. No rollback; explain zero-latency hold vs future-swipe ambiguity honestly.
- iOS/WebKit and Android/Chromium touch+WebGL2 (target iOS16+), coarse pointer/iPad MacIntel detection, not UA-only. Desktop phone prompt must allocate no GPU/assets. Landscape/background/fullscreen exit clears capture/input, pauses and stops RAF/vibration/Web Audio. Explicit resume, BFCache must not auto-resume.
- Fixed CSS/visualViewport/safe areas, no scroll/overscroll/selection/callout/drag/tap flash/pinch/double-tap zoom. Capture native touch/pointer defaults and selectionchange, not only canvas events; suppress pseudo-element selection too. Preserve settings buttons and attribution links. Resize events coalesce and update size+DPR together once.
- Fullscreen only on trusted Play/Resume/settings activation, standard/WebKit feature detect and catch denial. iPhone normal Safari tabs cannot be forced fullscreen; relative local manifest/PNG Apple icons + Share→Add to Home Screen fallback. No new service worker/offline/cache claims.
- Wallet coins/diamonds persist across runs via validated dinoplat3d-wallet-v1=1.coins.diamonds cookie, Vite BASE_URL path,1year/SameSite=Lax/Secure HTTPS. Coalesce writes off RAF, flush pause/navigation/disposal, corrupt/blocked storage cannot break play. Prototype client economy is not secure server storage. Hearts heal1 up to3 without reviving/clearing immunity. Settings/best optional localStorage.
- Event numeric payloads, subscribers installed once/unsubscribe. Haptics optional throttled feature detect (iOS may not support), one local MP3 sprite (160748B,13 Kenney CC0 cues + original16s music loop), one decoded mono buffer (<4MiB at48kHz), eight reused gain channels and at most eight one-shot SFX sources plus one music source. BufferSourceNodes are single-use by Web Audio design: bound/steal/disconnect them explicitly. Cache decode, vary step samples/pitch, compressor guards loudness. No AudioContext/autoplay before touch; music only during runs; pause/mute/background/dispose stop sources. Preserve art/audio originals, CC0 notices and public audio credit.
- Verify npm test, npm run build, npm run test:browser and PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1 npm run test:mobile where needed. Check actual GPU matrices under rotated views/capture/noncapture/negative/million-metre coordinates, LOD range and transitions, swept all-direction collision, route pilot, jump/duck/fatal freeze, 2D terrain seams/revisits, gestures/lifecycle/Retina/30Hz policy, cookies, context/asset failure and100 restarts.
- Warm all near/far models/poses/pickups before comparing memory. Test screenshots and native context antialias/DPR. Cloud Chromium/WebKit profiles/SwiftShader are NOT physical iOS/Android FPS measurements; report limits and never promise Brawl Stars/native-game FPS without device tests. - Keep README/ASSETS/VERIFICATION current; mark earlier results historical. Remove superseded runtime assets/tools but preserve GPL source archives/licences. No removed-API compatibility aliases just to satisfy obsolete tests.
- Preserve the never-played MP3 sync marker and one-time decoder-offset scan: WebKit and Chromium handle encoder padding differently. Shift cue/loop offsets after decode, not event time; never play the sync marker. Audio decoded bytes remain below4MiB, no frame-loop PCM scanning.

Keep original offline impact/death emphasis and queue a critical cue through initial decode/interrupted-context resume; pause/mute/dispose cancels it. No post-impact footsteps. Measure actual output in test-only analyser fixtures, never production audio polling.
